# Free-Snap-Tap — per-project bookkeeping

The Windows snap-tapping / rebind / macro product (pynput low-level hooks,
PySide6 GUI, asyncio tasks). Product code lives in its own repo — this folder
holds this agent repo's bookkeeping for it:
- `TODO.md` — the FST TODO entries (global ID sequence; counter in the root
  `TODO.md`): behavior decisions, code/tests, docs, environment.
- `todo_records.md` — the closed FST records (one-line records + full texts).
- `repo/` — the FST repo-doc parts (map, testgate, gotchas, run/test commands).
